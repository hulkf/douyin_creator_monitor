本图用「大白话 + 色块」展示：现在的耦合问题 与 将来的分层柜子。无需编程背景也能看懂。

现在 一个超大文件 + 一堆平铺脚本 + 直接读内部文件的控制面板

中间是一个近 3600 行的「上帝模块」run_creator_pipeline.py，它一个人干了所有活： 记日志、读配置、管状态、管账号钥匙、还亲手拼出每一步的「命令行字符串」去喊兄弟脚本上班。 网页/桌面面板则直接翻它的内部文件、直接按定时任务按钮。箭头颜色含义见底部图例。

强耦合：命令行字符串调用 控制层直接 import / 触发 共享文件 / 契约 / 内部状态

将来 分层柜子：只向下依赖，用「稳定接口」把各层隔开

把公共工具沉到最底层（core 内核），每个步骤变成一张标准「动作卡（Stage）」， 三处备份共用一个接口，账号钥匙独立成柜，网页/桌面面板只认一个稳定的 ControlAPI。 所有箭头只朝下，绝不回头——改任何一层都不会扯动别的层。

单向依赖（只向下） 稳定接口承重墙 控制层 / 触发定时任务 业务模块（采集/转写/纠正/飞书/备份/账号池） core 内核（公共工具）

一句话对照：现在 = 一个 3600 行大抽屉，用便利贴（命令行）喊兄弟脚本，面板直接翻内部文件； 将来 = 分层带标签的柜子，公共工具沉底、每步一张标准动作卡、三处备份一个口、账号钥匙独立柜、面板只认稳定 API。

不变的东西：平时一键启动的按钮、飞书「只新增+覆盖更新」、抖音仍走 MediaCrawler 采集、密钥与运行产物仍在被忽略的 local/runtime/logs/ 里。 迁移采用「绞杀者模式」分 6 阶段，每阶段都能一键跑通、可回滚，绝不一次性大重写。

本文件为单文件自包含（内联 CSS/SVG，无外部依赖），可离线双击打开。
